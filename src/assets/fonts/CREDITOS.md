# Fontes locais

As mesmas famílias já usadas pelo Pandora: Bricolage Grotesque, Hanken Grotesk e JetBrains Mono.
Os arquivos WOFF2 latinos foram preservados do build existente fornecido pelo usuário, sem modificar seu conteúdo.
São carregados por next/font/local para eliminar a necessidade de baixar fontes durante o build.

Origem das famílias: Google Fonts, https://fonts.google.com/.
