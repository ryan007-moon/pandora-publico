# Pandora School

Portal acadêmico integrado para estudantes, direção e transporte assistido no campus.

**[Acessar a aplicação](https://pandora-school.vercel.app)**

## Sobre o projeto

O Pandora reúne matrícula, disciplinas, notas, atividades, calendário, conquistas e frequência. A direção administra registros e entregas; o transporte interno atende estudantes com necessidade de apoio à mobilidade.

## Tecnologias

Next.js 15, React 19, TypeScript, Tailwind CSS, GSAP, Three.js, React Three Fiber, PostgreSQL, Supabase, Google Gemini API, Brevo, GitHub e Vercel.

## Escopo público

Seleção de arquivos reais de interface, estilos, utilitários e documentação para avaliação acadêmica. Não é uma distribuição executável completa: módulos privados e recursos não incluídos são necessários para executar o sistema. Nenhum registro de aluno, credencial, configuração de produção ou histórico privado é exportado.
